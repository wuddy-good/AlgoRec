# Модуль Прототипу Рекомендаційної Системи

## 🎯 Огляд

Це Python-реалізація гібридної рекомендаційної системи, яка поєднує:
1. **Content-Based Filtering (CBF)**: Рекомендації на основі характеристик об'єктів (назви, жанри, опис)
2. **Item-Item Collaborative Filtering (CF)**: Рекомендації на основі подібності між об'єктами, виведеної з історії оцінок користувачів

Модуль надає повністю функціональний CLI-інтерфейс для демонстрації роботи гібридного рекомендера, включаючи логування, кешування та юніт-тести.

## 🔧 Залежності

Залежності перелічені у `requirements.txt`:
- numpy, pandas для обробки даних
- scikit-learn для TF-IDF та інших ML операцій
- scipy для розріджених матриць та обчислення подібності
- Інші утиліти (tabulate, tqdm, тощо)

## 🧮 Опис Алгоритму

### Векторизація Контенту

Кожен об'єкт перетворюється на єдиний вектор ознак:

| Ознака | Метод Обробки |
| :--- | :--- |
| `description` | **TF-IDF** (максимум 5000 ознак, англійський стоп-лист) |
| `genres`, `actors` | **Multi-Hot Encoding** |
| `author_director` | **One-Hot Encoding** |
| `release_year` | **Min-Max Scaling** до `[0, 1]` |
| `avg_rating` | **Min-Max Scaling** до `[0, 1]` |

Всі розріджені матриці об'єднуються горизонтально (`scipy.sparse.hstack`), а фінальний вектор нормалізується за L2-нормою.

### Колаборативна Фільтрація

Використовується **Item-Item KNN** на основі косинусної подібності:
- Створюється матриця `Items x Users` з рейтингами
- Застосовується центрування за середнім користувача
- Обчислюється косинусна подібність між об'єктами
- Кешуються топ-K сусідів (за замовчуванням 10) для кожного об'єкта

### Гібридна Оцінка

Для об'єктів $i$ та $j$:

$$
s(i,j) = \alpha \cdot \text{content\_sim}(i,j) + (1 - \alpha) \cdot \text{cf\_sim}(i,j)
$$

де $\alpha = 0.7$ за замовчуванням (конфігурується)

### Профілювання Користувачів і Рекомендації

- **Профіль Користувача**: Зважений середній вектор контент-векторів оцінених об'єктів
- **Рекомендації**: Косинусна подібність між профілем користувача та неоціненими об'єктами
