# AlgoRec — Датасет для тестування алгоритмів рекомендацій

## Опис проєкту

Це мінімальний локальний датасет для експериментів із системою рекомендацій книг та фільмів. Містить три CSV-файли з тестовими даними.

## Структура файлів

### 1. users.csv
Містить інформацію про користувачів системи.

**Поля:**
- `id` — унікальний ідентифікатор користувача (ціле число)
- `username` — ім'я користувача (текст)
- `created_at` — дата реєстрації (формат: YYYY-MM-DD)

**Кількість записів:** 8 користувачів

### 2. items.csv
Містить інформацію про книги та фільми.

**Поля:**
- `id` — унікальний ідентифікатор елемента (ціле число)
- `item_type` — тип елемента ("book" або "movie")
- `title` — назва книги/фільму (текст)
- `genres` — жанри, розділені крапкою з комою (наприклад: "Драма;Комедія")
- `release_year` — рік випуску/публікації (ціле число)
- `author_director` — автор (для книг) або режисер (для фільмів)
- `actors` — актори для фільмів, розділені крапкою з комою (порожнє для книг)
- `description` — короткий опис змісту (текст)

**Кількість записів:** 25 елементів (12 книг + 13 фільмів)

### 3. ratings.csv
Містить оцінки користувачів для книг та фільмів.

**Поля:**
- `id` — унікальний ідентифікатор оцінки (ціле число)
- `user_id` — посилання на користувача з users.csv
- `item_id` — посилання на елемент з items.csv
- `rating` — оцінка від 1 до 5 (ціле число)
- `rating_date` — дата оцінки (формат: YYYY-MM-DD)

**Кількість записів:** 45 оцінок

### Крок 1: Розміщення файлів
Створіть папку для проєкту (наприклад, `algorec_dataset`) та покладіть у неї три CSV-файли: `users.csv`, `items.csv`, `ratings.csv`.

### Крок 2: Завантаження даних у Python
Відкрийте Jupyter Notebook або створіть Python-скрипт у тій же папці. Імпортуйте бібліотеку pandas та завантажте кожен CSV-файл у окремий DataFrame. Переконайтеся, що кодування файлів встановлено як UTF-8.

### Крок 3: Перевірка структури даних
Перегляньте перші кілька рядків кожного DataFrame, щоб переконатися, що дані завантажилися правильно. Перевірте типи даних у колонках та кількість записів.

### Крок 4: Обчислення середнього рейтингу
Щоб отримати середній рейтинг для кожного елемента (книги чи фільму), використайте DataFrame з оцінками. Згрупуйте оцінки за ідентифікатором елемента та обчисліть середнє значення рейтингу для кожної групи. Це дасть вам метрику популярності кожного item.

### Крок 5: Фільтрування за типом елемента
Щоб працювати окремо з книгами або фільмами, відфільтруйте DataFrame з елементами за полем `item_type`. Для книг використовуйте значення "book", для фільмів — "movie".

### Крок 6: Об'єднання даних
Для повноцінного аналізу об'єднайте три таблиці: приєднайте інформацію про користувачів до оцінок, а потім додайте інформацію про елементи. Це створить повний датасет із всією необхідною інформацією в одній таблиці.
